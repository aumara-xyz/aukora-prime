Capture uses `prepareCaptureBinding(...)`, owner approval of the resulting `memory.save` operation, then `captureAuthorizedRemembered(host, extraction, key, {operation, approval_proof})`. Unsigned capture and tombstone mutators are absent from the public service. Host identity contains distinct `owner_id` and `owner_subject`, plus task ID, privacy, scope, attribution, exact source receipt and source-event bytes. New pilot captures require the six extraction fields and fixed documented metadata: category `fact`, confidence `0.7`, sensitivity `none`, links omitted or empty, owner scope and local privacy. `observedAt` must equal the exact canonical `source.at` and `validFrom` its calendar date. Evidence comes from the selected original source event; evidence/body overrides and nondefault origin refuse. `pilot-capture.mjs` checks these choices before hashing or reservation and returns the unchanged input. Statement and attribution remain explicitly reviewed. Historical imports retain their metadata and original bytes and never pass through this validator or a new-note builder.

`prepareCaptureBinding` keeps the exact outer shape `{target_identity, state_version, canonical_parameters, memory_capture}`. NEW-save parameters have seven fields: `capture_sha256`, `idempotency_key_sha256`, `heads`, literal `statement`, trusted-host `attributed_to`, `capture_metadata`, and `evidence_quote`. The independent draft is exactly `{statement,attributed_to,capture_metadata,evidence_quote}`. Metadata keeps B's existing six-field profile: `{profile:'prime-pilot-memory-capture/v1',category:'fact',valid_from,observed_at,confidence_percent:70,sensitivity:'none'}`. Its integer confidence percentage binds the note's fixed numeric confidence `0.7` without adding a decimal to the operation envelope. The quote is the entire unchanged `event.text` from the selected source event, and may differ from the statement. Both are compared before consumption and under the owner lock; no quote is reconstructed from a digest or truncated. The browser-safe `capture-review.mjs` exports `validateCaptureMetadata`, strict four-field `validateCaptureDraft`, seven-field `validateCaptureReview`, and two-field internal `validateCaptureLiterals`. The approved save commits a durable prepared intent, rechecks state in the next transaction, dispatches once, then atomically saves records/events/chain/outbox/idempotency/effect receipt. In the configured retained profile, one dedicated PoolClient and its actual session advisory lock remain held across these transactions, file checkpoints and C settlement; private phase callbacks inspect that same backend's granted owner lock.
