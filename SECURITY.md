# Vulnerability reporting

A private security contact has not yet been confirmed for this repository. This remains a publication-preparation gap; this document does not claim that GitHub private vulnerability reporting is enabled.

The owner must confirm a monitored private contact or enable and verify GitHub private vulnerability reporting before this policy can provide a reporting destination. Public issues are suitable for non-sensitive bugs. Avoid posting credentials, private data or exploitable details publicly.

Reports should identify the affected source commit, relevant command or route, observed behavior, expected behavior and reproduction conditions. Distinguish source inspection, synthetic fixtures and an actual deployed path.

AUKORA is experimental. The [README](README.md) records the current status and known gaps. The [Golden Boundary paper](docs/AUKORA-GOLDEN-BOUNDARY.md) states the architecture's claims and limits.
