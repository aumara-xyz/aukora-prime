# Vulnerability reporting

GitHub private vulnerability reporting is enabled for this repository. [Report a vulnerability privately](https://github.com/aumara-xyz/aukora-prime/security/advisories/new), or open [Security → Advisories](https://github.com/aumara-xyz/aukora-prime/security/advisories) and choose **Report a vulnerability**. GitHub sign-in is required to submit a report.

Include the affected revision, relevant source or route, the impact and the smallest useful reproduction. Label source-only findings and anything you could not execute. Keep credentials, private conversations, personal data and unnecessary machine identifiers out of the report.

Public issues are suitable for non-sensitive bugs. Use the private route for exploitable details and coordinate disclosure with the maintainers. This policy promises no response time, bounty or independently verified notification coverage. No separate private email contact has been confirmed.
