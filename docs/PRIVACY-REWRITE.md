# Publication privacy rewrite

Private deployment identities, host destinations, account checkout paths, private document locators and operator relay identifiers were removed from the published history. Commit author names and upstream license attribution are preserved; private commit emails use the repository owner’s GitHub noreply identity or a reserved agent identity. A verified private recovery bundle and original-to-rewritten commit map are retained outside this repository.

The current pilot and deployed SSH fixture require independently retained, protected operator configuration. They refuse when it is absent. This source repair neither provisions the configuration nor qualifies a real deployment. Their ordinary synthetic checks are distinct from installed acceptance.

Historical source IDs and evidence hashes in documentation identify the original source or measured release. A rewritten historical generated file is redacted output, not a fresh build. Its old hash or signature does not attest to the redacted bytes. Original signed material remains in the private recovery archive; no receipt was regenerated by inventing matching historical bytes. The source license inventory retains its original baseline and records current metadata adaptations separately.

The release uses only sanitized refs. Pattern scans cover all reachable commit, tree, blob and tag objects, plus final tracked files. Upstream public contacts, reserved fixtures and parser sentinels are reviewed exceptions. Pattern scans do not establish the absence of encoded secrets, semantic personal information, unknown credential formats or image pixel information. GitHub cached views and other clones are separate from rewritten refs and must be addressed before public visibility when they retain private originals.

Operational source-review references in the fast profile and ops provenance point to their corresponding sanitized historical commits. This correspondence records redaction and attribution changes; it does not repeat the original review or certify installed identity.
