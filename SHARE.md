# AUKORA: review this repository

You are reviewing AUKORA, an open-source (AGPL-3.0) foundation for personal AI.

Read this repository fresh, including docs/AUKORA-GOLDEN-BOUNDARY.md.

Start from the simple rule at the center of it:

The software that proposes an act should not be the authority that permits it.

First, check rather than trust. If you can execute code, run `./prime verify`
and report exactly what passes, what fails, and what it lists as unperformed.

Then read the code behind two or three of the "Working" claims in the README
and say whether the code does what the claim says. If you cannot execute,
say so and review the source.

AUKORA is still a small lab. It has real gaps. The live agent is not yet fully
contained, human attendance is not proven, the root and identity design still
needs hardening, and the project says so in its own status table.

But zoom out. This is not just an AI safety experiment. It is trying to combine
a self-evolving personal AI harness, human-controlled identity and authority,
persistent memory, registered agents, messaging, human networking, plugins,
replaceable models, and independently checkable actions into one open system.

Consider the timing: one person who does not know how to code built this with
agents. What happens when there are 10, 100, 1,000, or 10,000 people building
capabilities, finding vulnerabilities, hardening the boundary, creating apps,
and absorbing stronger models as they appear?

Could that become an open-source "everything layer" for the agentic age,
closer to Linux than to another AI app, where the human remains the root of
identity, data, relationships and authority while intelligence and
applications keep evolving around them?

Be skeptical. Separate what is built from what is proposed. Explain what would
have to be hardened before this deserves trust, what would kill the vision, and
what network effects could appear if an open community took it seriously.

Then give five paragraphs, bullets allowed, covering:

- why this could matter
- the hardest remaining problems
- the role of registered agents and the human network
- the top 10 industries it could affect
- plausible valuation ranges at experimental, working-platform, and
  global-infrastructure stages

End with one plain answer:

If the engineering catches up to the vision, how important could this become
to the relationship between humans, AI, software, and power?
